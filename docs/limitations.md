# Limitations

- Learning gains over the baseline are not yet consistent across models.
- Full maps can still show weak global pathway organisation and overlaps; provenance, coverage and readability are assessed separately.
- Large models may use tiled or sub-range drawing; those metrics do not represent a single whole-graph layout.
- The default Atlas holds curated community maps from Escher, Human-maps, WikiPathways, Reactome, BRENDA, Metabolism Regulation and PANTHER; coverage for organisms or pathways absent from these sources is mostly algorithmic.
- The first setup needs network access and a C++ compiler; Linux and Windows are untested.
