# Limitations

- Learning gains over the baseline are not yet consistent across models.
- Full maps can still show weak global pathway organisation and overlaps; provenance, coverage and readability are assessed separately.
- Large models are laid out with fixed sub-ranges in some experiments; their metrics do not represent the whole graph.
- The default Atlas holds Escher, Human-maps, WikiPathways, Reactome, BRENDA, Metabolism Regulation and PANTHER maps; coverage for organisms or pathways absent from these sources is mostly algorithmic.
- The first setup needs network access and a C++ compiler; Linux and Windows are untested.
