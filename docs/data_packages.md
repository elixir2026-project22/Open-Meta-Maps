# Data packages

## Export the Atlas

`data export` writes the curated-structure Atlas (or a filtered part) as one portable `.tar.gz`:

```sh
python3 project.py data export                           # all sources, unique after dedup -> dist/openmetamaps-atlas-<registry date>.tar.gz
python3 project.py data export --out PATH                # another archive path
python3 project.py data export --source escher --source reactome
python3 project.py data export --licence CC0-1.0         # licence ids as in the manifest: CC0-1.0, CC0-1.0-data, CC-BY-4.0, MIT
python3 project.py data export --all-windows             # every cut window (48,334) instead of unique reaction sets (36,103)
```

| Entry | Content |
|---|---|
| `modules/<source>/<module_id>.json` | Escher JSON, the same format as the Atlas Browser download; curated geometry is uniformly scaled and translated, never rotated or mirrored |
| `manifest.json` | per module: `module_id`, `source`, `map_name`, `map_id`, `species`, `reaction_count`, `license`, `attribution`, `attribution_text` (the Atlas Browser manifest fields), plus `file`, `canonical_reaction_ids`, `provenance` (lineage, quality, source SHA-256, original instance, extraction block) and `also_in` (modules with the identical reaction set in other sources) |
| `README.md` | counts per source and licence |
| `THIRD_PARTY_NOTICES.md` | source credits and licences |

- Sources: `escher`, `reactome`, `wikipathways`, `wikipathways_geometry`, `human_maps`, `brenda`, `metabolismregulation`, `panther`, `ich360`.
- Dedup uses the canonical reaction-id set (geometry fingerprint for WikiPathways geometry-only windows), the same key as [`docs/images/atlas/atlas_overlap.json`](images/atlas/atlas_overlap.json). Filters apply first; each reaction set then keeps its largest module, so a filtered export holds every unique reaction set of the selection. A reaction set shared by several sources is exported once and lists the other modules under `also_in`.
- Entries are sorted, with fixed timestamps and owners, so re-running the command gives a byte-identical archive. The full default export takes about 30 s and is about 35 MB.

## Optional packages

The default Atlas is `data/open_core.sqlite` plus the in-tree extensions under `data/extensions/` (counts from [`data/atlas_registry.json`](../data/atlas_registry.json); About page regenerated by `python3 layout_atlas/navigation.py`). BRENDA, Human-maps, WikiPathways geometry-only, Metabolism Regulation, PANTHER and iCH360 ship in-tree and need no optional package. The only remaining optional package:

| Package | Content | Terms |
|---|---|---|
| `atlas-full` | the full `atlas.sqlite` (open-core Atlas snapshot) | see the package notice |

```sh
python3 project.py data list                 # what exists, size, terms, installed or not
python3 project.py data fetch atlas-full     # download, verify the SHA-256, install into data/
python3 project.py data fetch all
python3 project.py data fetch all --from DIR # install from a local folder or another base URL
```

- Each archive is checked against `data/packages.json` before anything is installed. An existing file is kept as `<name>.bak`; symlinks are never touched.
- With every package installed, `data/` has exactly the same files as the developer database, and the example map generated from a fresh clone is identical.
- Respect each package's terms (written under `data/package_notices/<name>.md` by the package install).
