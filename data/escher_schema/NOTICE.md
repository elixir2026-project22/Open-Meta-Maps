# Escher map schema

`vendor/escher/map-schema-1-0-0.json` is the official JSON schema of Escher maps (<https://escher.github.io>, <https://github.com/zakandrewking/escher>). Open Meta Maps validates every `map.json` it writes against it, so the maps open in Escher.

The file is used unchanged. The Escher licence (MIT, copyright The Regents of the University of California) is kept next to it in `vendor/escher/LICENSE`. The directory layout (`vendor/escher/…`) is kept because the code locates the schema as `REF/vendor/escher/map-schema-1-0-0.json`.
